YUVASHREE PORTFOLIO WEBSITE
============================

Files:
- index.html : all portfolio content and page structure
- style.css  : responsive styling, 3D CSS illustrations and animations
- script.js  : mobile menu, scroll progress, reveal animations
- README.txt : setup and publishing instructions

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

MAKE IT YOUR OWN
- Edit the content in index.html.
- Update email, phone, LinkedIn and project details if anything changes.
- Add real GitHub/live demo links to projects when available.
- The portfolio currently uses CSS-made visuals, so no image assets are required.
- Google Fonts are loaded from the web; the site still works with fallback fonts offline.

PUBLISH IT FREE TO GET A PUBLIC LINK
Option A — GitHub Pages:
1. Sign in to GitHub and create a new public repository, e.g. yuvashree-portfolio.
2. Upload index.html, style.css, script.js and README.txt to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for deployment; GitHub will display your public website URL in Settings → Pages.

Option B — Netlify Drop:
1. Visit https://app.netlify.com/drop
2. Drag the extracted website folder onto the page.
3. Follow the prompts to publish and receive a public URL.

CONTENT NOTES
Project descriptions are written as concise portfolio summaries based on the provided resume. Please ensure they accurately describe what you personally built before publishing. Add languages and any portfolio/repository links when ready.
